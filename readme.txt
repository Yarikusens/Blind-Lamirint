Blind Lamirint is one of my first console games. Unfortunately, it is the only game which code I didn't lose.
It was created in early 2023, so I didn't use AI at all for this.
The goal in this game is to find the exit from a lamirint/maze.
You can move the character ($) using WASD, but you can see only cells near you. F stands for finish.
Great feature: you can add new maps to the games just by creating a .txt file and placing walls (#), character ($) and finish (F) as you want.

I remember I worked on adding coins and portals to the game, but I lost the final version of the game unfortunately.
